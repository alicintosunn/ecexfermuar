ECEX HOSTING — VERCEL + SUPABASE
================================

Yeni üretim mimarisi:
- Uygulama ve API: Vercel üzerinde standart Next.js
- Veritabanı: Supabase PostgreSQL
- Dosyalar: Supabase Storage
- SMTP: Nodemailer üzerinden yönetim panelindeki SMTP ayarları

Vercel kurulumu:
1. Kaynak kodu GitHub/GitLab/Bitbucket deposuna gönderin.
2. Vercel'de Add New Project ile depoyu içe aktarın.
3. Framework Preset olarak Next.js seçin.
4. Install Command: `pnpm install --frozen-lockfile`
5. Build Command: `pnpm build`
6. Output Directory alanını boş/default bırakın.
7. Node.js 22 seçin.

Vercel Environment Variables:
- DATABASE_URL
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- SUPABASE_SERVICE_ROLE_KEY (secret)
- SUPABASE_STORAGE_BUCKET=media

Değişkenleri Production, Preview ve gerekiyorsa Development ortamlarına ekleyin. Production ve Preview için ayrı Supabase projeleri kullanılması önerilir.

İlk dağıtımdan önce Supabase migration'ını çalıştırın: `pnpm db:migrate`. Migration komutunu her Vercel fonksiyon başlangıcında çalıştırmayın.

Medya yüklemeleri Vercel fonksiyonunun içinden geçirilmez. Yönetici doğrulandıktan sonra kısa süreli imzalı yükleme URL'si üretilir ve tarayıcı dosyayı doğrudan Supabase Storage'a yükler. Böylece büyük dosyalarda Vercel request body sınırına takılma riski azaltılır.

Alan adı Vercel Project Settings > Domains bölümünden eklenir. Vercel'in gösterdiği DNS kayıtları domain sağlayıcısına uygulanır. SSL otomatik sağlanır.

Dağıtım sonrası kontrol: /, /tr/, /adminpanel, ürün sayfaları, görsel yükleme/görüntüleme, blog, pop-up, iletişim formu, SMTP test e-postası, robots.txt ve sitemap.xml.

Satın alınmış 25 GB NVMe/2 GB RAM/1 CPU klasik hosting bu mimaride uygulama sunucusu olarak gerekli değildir. İstenirse e-posta hizmeti veya bağımsız yedek alanı olarak kullanılabilir. Uygulamanın kendisi Vercel ve Supabase üzerinde çalışır.
